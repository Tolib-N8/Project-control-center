# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.9.0] — 2026-10-05

### Добавлено
- **Задачу можно передать агенту.** Кнопка с роботом открывает терминал проекта и запускает Claude Code или Codex с промптом из задачи: название, папка, срочность и просьба прогнать тесты и рассказать, что изменено. По умолчанию берётся агент, с которым ты последним работал в этом проекте. Другого агента можно выбрать через правый клик → «Передать агенту».
- У задачи появляется тег, где сейчас агент: «запускается», «в работе», «на проверку» или «не запустился», если сессия так и не появилась за 20 минут. Orbit находит сессию агента по названию задачи в первом промпте.
- Пока агент работает, Orbit обновляет данные каждые две минуты, а не раз в 15, чтобы статус не отставал.
- Повторный клик по роботу продолжает сессию в терминале. Клик по тегу открывает её в «Сессиях агентов». Правый клик → «Снять с агента» убирает назначение.
- Галочку «выполнено» по-прежнему ставишь ты: агент только отдаёт задачу на проверку.
- **Задачи из цели с ИИ.** Кнопка с искрами в шапке панели «Задачи» открывает окно: пишешь цель, выбранная модель разбивает её на 3–8 шагов в порядке выполнения и сама подбирает папку и срочность. Лишнее снимаешь галочкой, текст правишь прямо в списке, затем «Добавить N задач». Если результат не нравится — «Ещё вариант». Если модель не выбрана, окно подскажет, где это сделать.
- **У каждой нажимаемой иконки своя анимация** при наведении и клике:
  - меню слева: календарь перелистывается, квадраты проектов пружинят, чип сессий «дышит», ветка Git покачивается, колокольчик сигналов звенит;
  - шестерёнка проворачивается, стрелки толкаются в свою сторону, искры ИИ мерцают;
  - робот у задачи кивает, «+» в поле ввода поворачивается, чекбокс пружинит.

  При «Уменьшить движение» иконки стоят на месте.
- Выпадающие меню (сортировка, «Закоммитить», фильтры сессий) теперь рисуются средствами SwiftUI, поэтому их иконки тоже анимируются.

### Исправлено
- Недоступные кнопки теперь тускнеют. Раньше, например, «Разбить на задачи», пока ИИ думает, выглядела нажимаемой.
- «Продолжить с контекстом», «Начать рабочую сессию» и «Запустить в Claude Code» из брифа могли не найти `claude` или `codex`: терминальный скрипт запускает оболочку, которая не читает `~/.zshrc`. Теперь агенты запускаются по полному пути с тем же PATH, что в обычном терминале.

## [0.8.0] — 2026-10-05

### Добавлено
- **Задачи в проекте.** На экране проекта появилась панель «Задачи»: впишите задачу и нажмите Enter.
  - Открытые сортируются так: сначала срочные, потом по сроку, потом по времени создания.
  - У каждой задачи видно срок: «Сегодня», «Завтра», день недели или дата; просроченная дата — красным.
  - Отмеченная задача ещё мгновение остаётся на месте с галочкой, потом уходит в «Выполненные». Их можно раскрыть прямо в панели или открыть вкладкой «Готово».
- По правому клику задачу можно сделать срочной, задать срок, выбрать папку репозитория, переименовать (также двойным кликом) или удалить. Если в названии упомянута папка проекта («тесты в auth»), Orbit подставит `auth/` сам.
- Задачи хранятся локально в `~/.orbit/tasks.json`.
- Кнопка с роботом у задачи — заготовка под передачу задачи агенту; пока она только показывает подсказку.

### Изменено
- Экран проекта перестроен по макету: справа «Задачи» и «Git», «Дни работы» переехали под «Сессии агентов».

## [0.7.0] — 2026-10-05

### Добавлено
- **Английский интерфейс.** Весь Orbit — экраны, сигналы, план недели, уведомления, меню, настройки и онбординг — теперь доступен на английском. Язык по умолчанию берётся из системы (русский, если macOS на русском, иначе английский).
- Переключатель языка в **Настройки → Общие → Язык** («Как в системе» / «Русский» / «English») и на экране приветствия. Интерфейс переключается сразу, без перезапуска; системные пункты меню (О программе, Скрыть, Выйти) — со следующего запуска.
- ИИ пишет выводы, планы и брифы на выбранном языке. Кэш анализа хранится отдельно для каждого языка: русский кэш, накопленный раньше, остаётся в силе.

### Изменено
- Даты, числа и множественное число оформляются по правилам выбранного языка («28 сен» / «Sep 28», «1,5 ч» / «1.5 h», «12 500» / «12,500»).
- У тех, кто уже пользуется Orbit, интерфейс остаётся русским — язык можно поменять в настройках.
- В настройках анализа больше нет пустой плашки под карточками, когда выбраны локальные эвристики.

## [0.6.2] — 2026-10-03

### Исправлено
- После установки обновления из окна «Что нового» Orbit не перезапускался: пока открыто окно, приложение не закрывалось, и вспомогательный скрипт подменял файлы под работающей старой версией. Теперь окно закрывается перед выходом (с принудительным выходом через 3 с, если что-то мешает), скрипт никогда не трогает файлы, пока старая версия жива, а новую запускает отдельным экземпляром и проверяет, что она действительно стартовала.

## [0.6.1] — 2026-10-03

### Исправлено
- ИИ-анализ через «Claude · подписка» и Codex переставал работать, если Orbit запущен из Dock, Finder или перезапущен после обновления: приложение не находило `claude` в `~/.local/bin`, потому что этот путь добавляется только в `~/.zshrc`. Теперь CLI ищутся в стандартных папках и через интерактивную оболочку пользователя, а запускаются по полному пути с тем же PATH, что в терминале.

## [0.6.0] — 2026-10-03

### Добавлено
- Экран приветствия в начале онбординга: логотип собирается, затем появляются «Orbit», «Вайбкодинг без хаоса. Проекты, агенты и неделя — на одной орбите.» и подпись «от вайбкодера к вайбкодерам». По «Начать» логотип перелетает в верхнюю панель настройки.

- Релизы выходят в оформленном **`.dmg`**: окно в цветах Orbit, слева приложение, справа «Программы», между ними стрелка — перетащите и готово. Окно собирает `scripts/make-dmg.sh`.

### Изменено
- При первом запуске заставка не играет — логотип анимируется на экране приветствия.
- Архив `.zip` остаётся в релизе только для встроенного обновления.

## [0.5.0] — 2026-10-03

### Добавлено
- Встроенные обновления из GitHub Releases: Orbit проверяет новую версию при запуске и каждые 6 часов, показывает плашку в сайдбаре и уведомление, а по кнопке «Установить и перезапустить» скачивает архив, проверяет SHA-256, версию и подпись, заменяет себя и перезапускается. Предыдущая версия сохраняется в `~/.orbit/updates/previous`.
- «Orbit → Проверить обновления…», а в Настройках → Общие — автопроверка, установка без вопроса, пропуск версии.
- `scripts/release.sh X.Y.Z` — выпуск версии одной командой: номер версии, коммит, тег, сборка из тега, релиз на GitHub.

## [0.4.0] — 2026-10-03

### Добавлено
- Анимация запуска (~1,4 с): плитка логотипа появляется, орбита прорисовывается, луна делает круг и встаёт на место, затем логотип перелетает в строку с кнопками окна. Не показывается при «Уменьшить движение»; отключается флагом `--no-splash`.

## [0.3.0] — 2026-10-03

### Добавлено
- Анимации и переходы в сдержанном стиле — короткие пружины без отскоков:
  - переход в проект выезжает справа, возврат — слева, разделы сайдбара сменяются мягким подъёмом; старый экран исчезает за 80 мс, поэтому экраны не накладываются;
  - выделение в сайдбаре, во вкладках и в списке сессий скользит к выбранному пункту;
  - карточки, строки и колонки недели появляются каскадом;
  - числа здоровья и счётчики перекатываются, полосы и графики коммитов вырастают;
  - блоки плана плавно переезжают между днями, отложенные сигналы уезжают влево, шаги онбординга листаются;
  - подсветка при наведении, лёгкое нажатие у кнопок, вращающийся значок синхронизации и пульсирующий значок ИИ-анализа.
- Учитывается системная настройка «Уменьшить движение»: остаются только короткие затухания.

### Изменено
- Логотип и название перенесены в одну строку с кнопками окна.

## [0.2.0] — 2026-10-03

### Добавлено
- ИИ-анализ с выбором провайдера: **Claude по подписке** (через Claude Code, без API-ключа), Claude API, Codex по подписке ChatGPT, Ollama, любой OpenAI-совместимый API. Локальные эвристики остаются по умолчанию и как запасной вариант.
- Модель пишет вывод по проекту, следующие шаги и цель дня, разбирает сессии агентов («что сделано», «где застрял», рекомендация), генерирует сообщения коммитов и брифы для агентов.
- Окно настроек (⌘,): провайдер, модель, глубина анализа, ключи API в связке ключей macOS, проверка подключения.
- Выбор провайдера в онбординге и статус ИИ-анализа в сайдбаре.

### Изменено
- Анализ проекта повторяется только при изменении фактов и не чаще раза в 6 часов (настраивается) — чтобы беречь лимиты подписки.
- Неотслеживаемые файлы помечаются `?`, а не `A`.
- Заголовки сессий очищаются от маркеров вложений `[Image #1]`; кэш разобранных логов пересобирается.

## [0.1.0] — 2026-10-03

Первая рабочая версия Orbit.

### Добавлено
- Онбординг в три шага: поиск репозиториев, источники логов агентов, ритм недели.
- Экран «Неделя»: проект в фокусе с целью дня, «Требует внимания», план недели с фактическими часами, таблица проектов; первый запуск с прогрессом анализа.
- Планировщик недели: автоплан по здоровью проектов и сигналам, «Другой вариант», ручная правка часов, перетаскивание проектов на дни.
- Экраны «Проекты» и «Проект»: здоровье с трендом за 14 дней, сессии агентов, незакоммиченные файлы, коммит с готовым сообщением, дифф, дни работы.
- «Сессии агентов»: парсинг логов Claude Code, Codex и Aider — итог, где застрял, рекомендация, ход сессии, транскрипт, «Продолжить с контекстом».
- «Git»: график коммитов агентов и ваших, таблица репозиториев, fetch всех, rebase и удаление заброшенных веток.
- «Сигналы»: семь правил мониторинга, отложенные и решённые сигналы, уведомления macOS.
- Фоновая проверка каждые 15 минут, утренняя сводка, автоплан по воскресеньям, строка меню.
- Локальное хранение в `~/.orbit` с кэшем разобранных логов.

### Известные ограничения
- Выводы и план строятся эвристиками; Claude API и Ollama — в следующих версиях.
- Нет интеграции с GitHub (PR, CI), Telegram и почтой; Cursor только определяется.
